# Scene Name Mapping (Canonical s_* Naming)
# Last updated: 2026-03-05

This file is the single source for scene naming and scene intent.
All training/play/eval commands should use the canonical s_* / e_* names below.

## A) Mainline Scenes (Avoid Training)

1) s_avoid_basic
- Type: Avoid mainline bootstrap scene
- Current content: 3-stage plane curriculum (all obstacles are PhysX primitive actors)
  - Stage 1: open sparse capsules (3-5), min spacing 1.2m
  - Stage 2: open dense mixed capsules+boxes (6-8), min spacing 0.7m
  - Stage 3: straight corridor with two long box walls; width starts at 1.20m and shrinks to 0.85m by collision metric
- Status: Active (new baseline entry)
- Note: Stage switch is metric-driven (recent-100 collision rate + min episode gate), not fixed iteration.

2) s_cylinder
- Type: Avoid training scene
- Content summary: Cylinder-style obstacle layout
- Status: Active

3) s_narrow_passage
- Type: Avoid training scene
- Content summary: Narrow passage / gate-constrained layout
- Status: Active

4) s_step_field
- Type: Avoid training scene
- Content summary: Step-like terrain + obstacle constraints
- Status: Active

5) s_dense_obstacles
- Type: Avoid training scene
- Content summary: Dense obstacle distribution
- Status: Active

6) s_ood_holdout
- Type: Structured OOD evaluation scene
- Content summary: Holdout distribution for robustness check
- Status: Eval-only (not main training)

## D) Paper Scenes (e_*)

19) e_L_conflict
- Type: Paper conflict showcase scene
- Content summary: Flat field + target goes straight then 90-degree right turn;
  one cylinder (diameter 0.30m) is tangent to both legs at the inner corner
  and is created as a scene obstacle actor (not terrain imprint).
- Status: Active (paper demo / conflict validation)

20) e_S_corridor
- Type: Paper continuous-turn showcase scene
- Content summary: Flat field + narrow S-shaped corridor built by continuous trimesh walls;
  target moves along the corridor centerline with a smooth scripted S trajectory
  to test continuous-bend follow behavior.
- Status: Active (paper demo / continuous-bend validation)
