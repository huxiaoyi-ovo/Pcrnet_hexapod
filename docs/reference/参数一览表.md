# 参数一览表

> 文档状态：当前参考（Reference）。用于参数口径查询，不作为唯一规范；最终以 V7 技术方案与代码实现为准。

**

| 名称（日志 / 参数）               | 命名来源拆解                      | 指标类型          | 理论范围                   | Phase 1 合理区间    | 当前表现解读           | 训练中的真实含义           |
| ------------------------- | --------------------------- | ------------- | ---------------------- | --------------- | ---------------- | ------------------ |
| **Mean reward**           | 所有 reward 加权和               | 总体            | 无上界                    | **8 ~ 15**（正常）  | 8–10 ✔           | 是否“整体在学”，不是单项好坏判断  |
| **episode_length**        | 一回合步数                       | 稳定性           | `[0, max_episode_len]` | **> 90% max**   | ~480–495 ✔       | 不摔、不翻、不早停          |
| **rew_tracking_lin_vel**  | tracking + linear velocity  | 核心正奖励         | `[0, 1]`               | **0.55 ~ 0.75** | ~0.55–0.65 ✔     | 会不会“按指令往前走”        |
| **rew_tracking_ang_vel**  | tracking + angular velocity | 核心正奖励         | `[0, 1]`               | **0.55 ~ 0.75** | ~0.60–0.70 ✔     | 转向是否稳定、听话          |
| **rew_camera_stability**  | camera + stability          | 稳定质量指标        | `(0, 1]`               | **0.05 ~ 0.25** | ~0.09–0.11 ✔     | 是否“走得稳”，Phase2视觉前提 |
| **rew_base_height**       | base + height               | 姿态约束          | `[0, 1]`               | **0.20 ~ 0.35** | ~0.24–0.26 ✔     | 身体高度是否合理           |
| **rew_collision**         | collision 事件惩罚              | 安全约束          | `≤ 0`                  | **接近 0**        | -0.02 ~ -0.03 ✔  | 是否经常撞非足端           |
| **rew_ang_vel_xy**        | angular velocity (x,y)      | 稳定惩罚          | `≤ 0`                  | `>-0.1`         | -0.05 ~ -0.07 ✔  | 抑制横滚/俯仰抖动          |
| **rew_lin_vel_z**         | linear velocity z           | 稳定惩罚          | `≤ 0`                  | `>-0.05`        | -0.02 ~ -0.03 ✔  | 抑制上下跳              |
| **rew_dof_acc**           | joint acceleration          | 平滑性惩罚         | `≤ 0`                  | `>-0.25`        | ~-0.18 ~ -0.22 ✔ | 防止高频关节抖动           |
| **rew_action_rate**       | action change rate          | 平滑性惩罚         | `≤ 0`                  | `>-0.35`        | ~-0.30 ✔         | 防止“抽搐式控制”          |
| **rew_torques**           | joint torques               | 能耗惩罚          | `≤ 0`                  | `>-0.05`        | ~-0.01 ✔         | 是否用力过猛             |
| **rew_feet_air_time**     | feet + air time             | 步态奖励          | `[-, +]`               | 接近 0            | ~0.005 ✔         | 是否形成自然步态           |
| **rew_stand_still**       | stand still                 | 约束项           | `≤ 0`                  | 接近 0            | ~-0.01 ✔         | 防止乱动               |
| **terrain_level**         | terrain difficulty level    | curriculum 状态 | `[0, max]`             | **> 1 且逐步升**    | **~5.8 ✔**       | Curriculum 是否真正工作  |
| **Mean action noise std** | policy exploration          | 探索度           | `[0, ~1]`              | **0.35 ~ 0.5**  | ~0.40 ✔          | 是否还在探索阶段           |
| **BC loss**               | behavior cloning            | 专家引导          | `≥ 0`                  | **→ 0**         | 0 ✔              | 专家已退出，纯 RL         |
| **Value loss**            | critic loss                 | 估值稳定性         | `≥ 0`                  | `< 0.05`        | ~0.016 ✔         | critic 没崩          |
| **Surrogate loss**        | PPO objective               | 策略更新          | 小量                     | ≈ 0             | 正常 ✔             | PPO 更新幅度健康**       |
