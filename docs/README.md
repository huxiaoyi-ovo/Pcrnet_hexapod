# 文档索引

## 职责

- 根目录 [`AGENTS.md`](../AGENTS.md)：常驻协作、授权和按需读取入口。
- [`agents/REVISION_GUIDE_CN.md`](agents/REVISION_GUIDE_CN.md)：返修证据链与表述边界。
- [`agents/EXPERIMENT_RULES_CN.md`](agents/EXPERIMENT_RULES_CN.md)：实验、场景、传感和部署输入口径。
- [`agents/TRAINING_AUDIT_CN.md`](agents/TRAINING_AUDIT_CN.md)：训练一致性与奖励生命周期审计。
- [`agents/HANDOFF_TEMPLATE_CN.md`](agents/HANDOFF_TEMPLATE_CN.md)：按需生成会话交接摘要的模板。
- [`TODO_LOG.md`](../TODO_LOG.md)：重大改变、方向调整和里程碑。
- [`DEBUG_SUMMARY_CN.md`](../DEBUG_SUMMARY_CN.md)：调试总结；使用前查看当前内容。
- [`PROJECT_OVERVIEW_CN.md`](../PROJECT_OVERVIEW_CN.md)：项目背景、边界和文档职责。
- [`NAVIGATION.md`](NAVIGATION.md)：按任务查找当前规范、参考和历史材料。

V7 技术方案属于阶段性背景；后续已确认且有日期的实验决策按各自适用范围优先。当前实现和验收状态以源码、配置、结果及里程碑记录为准。

`CONTEXT_HANDOFF_SUMMARY.md` 是按需生成的交接记录名称，当前仓库没有该文件。

## 目录

- `specs/`：技术规范与方案。
- `operations/`：训练、评测与运行手册。
- `reference/`：参数、术语与稳定参考。
- `archive/`：历史草案和阶段记录，仅作参考。
- `agents/`：按具体任务读取的协作专项指南。
