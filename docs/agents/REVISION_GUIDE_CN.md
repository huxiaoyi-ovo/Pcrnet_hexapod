# 返修与审稿回应指南

仅在处理论文返修、审稿意见、回复信或相关正文/图表时读取。本指南负责证据链和表述边界；具体科研决策以用户已冻结口径和当前返修材料为准。

## 最小证据链

逐条按“审稿原问题 → 回复信回答 → 正文/图表落点 → 已有证据”核对，确认回应直接覆盖了问题且正文没有引入新疑问。区分三类内容：原稿已有、为消除歧义而澄清、确实新增的方法或实验。优先做能闭合证据链的最小修改；已有证据不足时指出缺口，不补造结果或科学事实，也不因形式完整而随意新增实验。

保留用户明确要求保护的措辞、数字和结论原样。作者确认的信息与独立核验的信息分开标注；未知相机参数、数据来源、实验设置和实测量不得推断成事实。CPU、仿真、真实 checkpoint、硬件运行各自按实际证据表述。

## 决策与验证

返修阶段从第一性原理选择性能、正确性、仿真—实机一致性和回应说服力综合最合适、可实施的方案。只有会影响核心架构、训练成立或论文结论的高风险不确定性才安排专项验证；低风险猜测采用合理默认，不为追求形式上的万无一失扩展审计、消融、场景或参数。必要实现正确性检查不能省略，也不能据此虚构证据。

每次修改后说明对应的审稿问题、回复信与正文/图表落点，以及支撑它的现有证据；若还留有作者确认但未独立验证的事项，准确标注边界。
