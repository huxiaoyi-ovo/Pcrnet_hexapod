V5 训练链路与参数清单

一、训练链路（V5 cmd-space MoE）
- 环境初始化：HierarchicalHexapodEnv 创建 Isaac Gym 任务，禁用高层 command 重采样，加载冻结低层策略。
- 高层频率：10Hz，低层 50Hz（decimation=5）。
- 观测构成：
  - state：9 维基础状态 + 1 维 prev_gate_y（总 10 维）
  - goal：2 维相对目标
  - affordance：3x16x16（occupancy / passable_gap / low_obstacle）
  - difficulty：1 - passable_gap.mean()
- aff_stack：按通道堆叠 aff_stack 帧（默认 1），训练/ckpt 必须一致。
- T1 弱遮挡（可选）：仅冻结/丢失 policy 输入的 goal，不改变 env 内部目标与奖励逻辑。
- 高层输出：
  - follow/avoid：CmdVelExpert -> cmd_vel=[vx,vy,omega]
  - moe：GatePolicy -> y，cmd = y*cmd_F + (1-y)*cmd_A
  - Gate 的 difficulty 输入默认关闭（需显式开启）
- 命令后处理：CommandPostProcessor 统一限幅、变化率限制、风险缩放（训练/演示一致）。
- 低层执行：每高层步执行 decimation 次低层动作，累计奖励与 done。
- 奖励：NavigationRewardFunction，核心为 gate_smooth + risk_barrier + collision，另含目标接近/朝向/稳定/时间等项。
- PPO：GAE + clipped loss；moe 模式只用 gate 的 logprob/value/adv，expert 冻结。

二、训练脚本参数（默认值） legged_gym/scripts/train_highlevel.py
- 基础：
  --mode {teacher,student}（必填）
  --skill {follow,avoid,moe}（默认 follow）
  --task hex_ground（V5 主线默认）
  --aff_stack=1
  --num_envs=4096
  --decimation=5
- PPO：
  --num_iterations=1000
  --num_steps=24
  --num_epochs=5
  --mini_batch_size=4096
  --lr=1e-4
  --gamma=0.99
  --gae_lambda=0.95
  --clip_range=0.1
  --value_loss_coef=0.5
  --entropy_coef=0.01
  --distill_coef=1.0
  --max_grad_norm=0.5
- MoE/安全：
  --cmd_slew_lin=0.2
  --cmd_slew_ang=0.4
  --cmd_safe_dist=None（默认 clearance）
  --cmd_free_dist=None（默认 clearance_free）
  --gate_safe_clamp（可选）
  --gate_safe_max=0.3
  --moe_expert_deterministic（可选）
  --gate_use_difficulty（可选，默认关闭）
  --moe_use_student_aff（可选，强制使用 student affordance）
  --disable_risk_scale（可选，禁用风险缩放）
- T1 弱遮挡：
  --t1_goal_occlusion（开关）
  --t1_goal_occlusion_prob=0.02
  --t1_goal_occlusion_len=10
- 模型：
  --low_level_ckpt（必填）
  --follow_ckpt/--avoid_ckpt（moe 必填）
  --teacher_ckpt/--vision_ckpt（student 模式）

三、CommandPostProcessor 参数与逻辑
- 限幅：max_cmd=(max_lin, max_lin, max_ang)
  - 默认来源 nav_cfg.max_lin_vel_command / nav_cfg.max_ang_vel_command
  - fallback 默认：0.8 / 1.5
- 变化率限制：max_delta=(slew_lin, slew_lin, slew_ang)
  - CLI 默认：0.2 / 0.4
- 风险缩放：
  - scale = clamp((clearance - safe) / (free - safe), 0, 1)
  - cmd = cmd * scale
  - safe/free 默认从机器人 clearance 推断，可由 CLI 覆盖
  - 训练/演示完全一致（都用 env.post_processor）

- 奖励公式关键点：
  gate_smooth 仅依赖 |y_t - y_{t-1}|
  risk_barrier 连续指数形式 exp(-(d - safe)/tau)
  collision 为强惩罚 + done

五、策略网络结构（CmdVelExpert / GatePolicy）
- AffordanceCNNEncoder：3x16x16 -> Conv(32) -> Conv(64) -> Conv(128) -> Flatten -> FC(128)，含 CoordConv
- StateEncoder：state_dim -> 64 -> 64 -> out(64)
- GoalEncoder：goal_dim -> 32 -> out(32)
- 融合层：128 + 64 + 32 + 1(difficulty) -> hidden_dim=256
- CmdVelExpert 输出：
  mean/std（std clamp [0.01,1.0]）
  cmd = tanh(raw) * cmd_scale
- GatePolicy 输出：
  Beta(alpha,beta)，alpha/beta = Softplus + 1.0

六、MoE Gate 训练细节
- follow/avoid 在 Gate 训练时 requires_grad=False 且 no_grad + detach
- RolloutBuffer action 只存 gate_y（action_dim=1）
- logprob/value/adv 只来自 GatePolicy

七、演示链路（play_highlevel）
- 支持 --skill follow/avoid/moe；moe 需 --follow_ckpt/--avoid_ckpt
- cmd_slew_lin/ang 与 cmd_safe/free 参数与训练一致
- gate 模式打印 gate_y，输出风险缩放/通行/碰撞等日志

八、S1–S6 场景映射（V5）
- S1：Corridor（走廊 + 门洞收缩段 + 通道内离散障碍）
- S2：Forest（随机静态障碍，稀疏→中等）
- S3：Doorway（房间-门洞拓扑）
- S4：Crossing（动态横穿）
- S5：Sparse→Dense（非平稳密度切换）
- S6：结构化 OOD（cluster / nonconvex / maze 混合采样）
- S6 模板消融：在 hex_s6_config.py 中用 ood_template 固定模板，或用 ood_template_probs 设置采样比例
